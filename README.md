# Network_Monitot_UI

网络信息展示平台 —— 一个**单文件、零第三方依赖**的网络监控大屏（数据可视化驾驶舱）。

## 特性

- **单文件交付**：`network-cockpit.html` 一个文件搞定，断网也能跑（手写 SVG 图表，无 CDN 依赖）。
- **多分辨率自适应**：支持等比缩放 / 铺满 / 响应式重排 / 运行时切换四种适配模式，适配 1080p～4K 及超宽屏。
- **可编辑大屏**：模块显隐与排序、标题双击改名、主题色与密度调节、单页 ↔ 分屏多页随时切换。
- **多数据源接入**：
  - **Zabbix**：使用账号密码登录（非 API KEY），自动获取并复用 `sessionid`。
  - **Fortinet FortiAnalyzer**：JSON-RPC / REST 双模式，获取攻击与拦截数据，字段映射可配置。
  - 支持通过反向代理注入认证，规避跨域（CORS）。
- **离线地图**：内置示意图，并支持用户自导入合规底图（基于角点经纬度线性投影）。

## 适用场景

面向企业 / 园区网络管理员，统一展示多厂商设备（Cisco Catalyst / Nexus、Firepower、Palo Alto、Fortinet 等）的运行状态、安全态势与业务容量。

## 使用

直接用浏览器打开 `network-cockpit.html` 即可。数据源地址与凭据在「数据接入」面板配置。

> 注：为符合国内地图测绘合规要求，未集成在线地图服务，改用离线示意图 + 自导入底图方案。
